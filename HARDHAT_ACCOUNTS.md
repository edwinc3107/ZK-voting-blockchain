# Hardhat Test Accounts for MetaMask

These are the default Hardhat accounts. Import them into MetaMask to test the voting system.

## How to Import:

1. Open MetaMask
2. Click the account icon (top right)
3. Click "Import Account"
4. Select "Private Key"
5. Paste one of the private keys below
6. Click "Import"

1. Import at least 2 accounts:
   - One Board Member (to create cases)
   - One Verified Voter (to vote)

2. Make sure you're on **localhost network** (chain ID: 1337)

3. Switch between accounts in MetaMask to test different roles
